## The entry

> For best battery life, switch off your smoke detector overnight — it draws power even when there is no fire.

108 characters, one line, no trailing newline. The program checks the 1–140 character gate, the single-line rule, and reads back what it wrote to confirm the bytes are identical before finishing.

## Run it

Node 22 or later, nothing to install. It writes the entry to `/output/entry.txt`, or to `$MAKEFUN_OUTPUT_DIR/entry.txt` when that is set.
